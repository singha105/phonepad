Set up motion (one time)

iPhone only shares motion with secure pages, so PhonePad has a second, secure address. Your phone needs to trust it once:

  1. Download the PhonePad certificate, then tap Allow.
    Download certificate
  2. Open Settings → Profile Downloaded → Install (enter your passcode).
  3. Then Settings → General → About → Certificate Trust Settings and turn on PhonePad local CA.
  4. Come back here and open the secure page. Add that one to your Home Screen.
    Open secure page

The certificate only works for addresses on your own network, so it can't be used to fake real websites.
